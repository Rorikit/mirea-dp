# Бизнес-правила

- BR-01: Excel `id` сохраняется как строковый `source_id`; внутренний ключ — UUIDv7. Уникальность: `(event_id, source_id)`.
- BR-02: нормализация не меняет исходные поля. ФИО: Unicode NFKC, trim, пробельные последовательности в один пробел, lowercase, `ё→е`; порядок/дефисы/апострофы сохраняются. Группа: NFKC, trim, пробелы, uppercase. Институт: NFKC, trim, пробелы, lowercase только в normalized.
- BR-03: управляющие символы и Excel-формулы в обязательных ячейках — ERROR; необычная группа по `^[А-ЯЁA-Z]{2,6}-?\d{2}-\d{2}$` — WARNING, не отказ.
- BR-04: одинаковый `source_id` в файле блокирует batch; одинаковые нормализованные ФИО+группа+институт при разных ID — WARNING и никогда не объединяются.
- BR-05: стратегия C. Отсутствующие становятся inactive только после отдельного согласия; зарегистрированные и история сохраняются, активные QR отзываются.
- BR-06: регистрация использует ровно одно точное совпадение active по `(event, normalized_name, normalized_group)`; институт не вводится; fuzzy matching запрещён.
- BR-07: `(event_id, source_student_id)` регистрации уникален; повтор регистрации идемпотентен.
- BR-08: `OUTSIDE` принимает ENTRY, `INSIDE` принимает EXIT. Каждое успешное сканирование создаёт неизменяемый `AttendanceEvent`.
- BR-09: QR случаен (не менее 128 бит энтропии), хранится только SHA-256/HMAC hash, живёт 15 минут, одноразовый; не более одного ACTIVE на registration.
- BR-10: после ENTRY автоматически создаётся EXIT; после EXIT ENTRY создаётся по явной кнопке, чтобы не выставлять лишний bearer token.
- BR-11: `AttendanceEvent` — успешный факт, `ScanAttempt` — каждая попытка. Повтор одного idempotency key возвращает прежний ответ.
- BR-12: метрики: уникальный посетитель — registration с ≥1 успешным ENTRY; «сейчас» — `presence_status=INSIDE`; вход/выход — количество соответствующих AttendanceEvent.
- BR-13: время хранится UTC, отображается MSK; расписание «идёт сейчас», когда `starts_at <= server_now < ends_at`.
- BR-14: опасные операции не удаляют историю; архивирование события требует admin, повторной аутентификации, контрольной фразы и аудита.

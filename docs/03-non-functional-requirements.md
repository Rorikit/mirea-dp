# Нефункциональные требования

| Область | Цель MVP | Проверка |
|---|---|---|
| Доступность | 99,5% в окне 07:00–22:00 MSK дня события | Мониторинг uptime и rehearsal — генеральная проверка. |
| Производительность | p95 чтения < 500 мс, сканирования < 800 мс без учёта сети; preview 50k строк < 60 с | Нагрузочные тесты на согласованном профиле. |
| Конкурентность | Ровно одно событие для одного QR и одного idempotency key | Параллельные интеграционные тесты PostgreSQL. |
| Масштаб | 50k студентов, 100 операторов, 50 RPS пикового сканирования (допущение) | k6/Locust после уточнения. |
| Безопасность | HTTPS, least privilege — минимальные привилегии, OWASP-контроли, отсутствие ПДн/токенов в логах | SAST, dependency scan, DAST и review. |
| Надёжность | RPO ≤ 15 мин, RTO ≤ 60 мин в день события | Проверяемое резервное копирование и восстановление. |
| Доступность интерфейса | WCAG 2.2 AA как ориентир, touch target ≥ 44×44 px, без передачи смысла только цветом | Lighthouse + ручные сценарии. |
| Совместимость | Последние 2 версии Chrome/Safari/Firefox/Edge; iOS Safari и Android Chrome | Матрица устройств. |
| Сопровождаемость | Модули не обращаются к чужим таблицам минуя публичные сервисы; миграции версионируются | Архитектурные тесты и review. |
| Локализация времени | Хранение UTC, отображение `Europe/Moscow` | Тесты границ дат и рассинхронизации. |

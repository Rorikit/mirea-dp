# Mobile First UX

Публичный путь: регистрация → QR/статус → карта/расписание. Персонал: login → scanner (главный экран) → последние операции. Admin desktop-capable, но критические previews доступны на узком экране таблицами-карточками.

- Нижняя навигация, ключевые действия в зоне большого пальца, touch targets ≥44 px, поля с label и подсказкой.
- QR: белое quiet zone — свободное поле, высокая контрастность, без overlay, яркость экрана по подсказке, таймер и назначение текстом.
- Светлая/тёмная тема; контраст AA; успех/ошибка отличаются иконкой, заголовком, текстом и вибрацией, не только цветом.
- Для каждого экрана: skeleton loader, empty state, retry, offline banner. Мутация при неизвестном результате повторяется с тем же idempotency key.
- Сканер: permission rationale до browser prompt, fallback ручного ввода, debounce одинакового payload 2 секунды, камера останавливается в background.
- Ошибки не раскрывают чужие данные. Focus management, `aria-live`, клавиатурная навигация и reduced motion обязательны.
- Корпоративные цвета и логотип берутся только из утверждённого брендбука; до его получения используются нейтральные design tokens, не выдуманный логотип.

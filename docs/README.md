# Архитектурная документация

Документы `01`–`21` образуют согласованный baseline MVP; `adr/` фиксирует ключевые решения. Нормативные приоритеты при конфликте: принятый ADR → business rules → API/data design → обзор. Изменение контракта требует обновить связанные документы и ADR.

Проверка перед реализацией: все открытые вопросы имеют владельца; enum/термины совпадают; Mermaid рендерится; каждый endpoint имеет роль/schema/codes/idempotency/rate/transaction; threats и tests покрывают критические инварианты.

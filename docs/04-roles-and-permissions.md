# Роли и права

RBAC (role-based access control — управление доступом по ролям) проверяется в API. Студентская сессия ограничена одной регистрацией и не является ролью персонала.

| Возможность | Студент | Оператор | Администратор |
|---|:---:|:---:|:---:|
| Публичный поиск/регистрация | ✓ | ✓ | ✓ |
| Собственный профиль/QR | свой | — | по админ API |
| Карта/расписание | published | published | CRUD |
| Сканирование | — | ✓ | ✓ |
| Последние сканы | — | свои | все |
| Студенты/фильтры | — | — | read/update |
| Импорт/preview/confirm/cancel | — | — | ✓ |
| Операторы | — | — | CRUD, кроме самоблокировки последнего admin |
| Статистика/экспорт | — | — | ✓ |
| Аудит/настройки/архивирование | — | — | ✓ |

Объектные проверки дополняют роль: `event_id` из токена/сессии должен совпадать с объектом; оператор видит только собственный recent; студент — только registration из своей сессии. Все отказы аудируются без секретов.

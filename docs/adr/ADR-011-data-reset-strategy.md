# ADR-011: Стратегия сброса данных

- Статус: принято
- Решение: product API не выполняет hard delete/«сброс статистики». Текущее Event архивируется, registration/scanning выключаются, active QR отзываются; новое Event создаёт чистую область данных. Экстренное удаление — отдельная юридически утверждённая runbook-процедура с backup/audit.
- Альтернатива cascade delete отклонена из-за потери истории, аудита и ошибочного нажатия.
- Последствие: storage растёт, нужны retention/archive policies до production.

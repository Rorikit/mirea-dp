# ADR-001: Модульный монолит

- Статус: принято
- Контекст: MVP, небольшая команда, единые транзакции импорта/scan.
- Решение: асинхронный FastAPI modular monolith на SQLAlchemy 2 + asyncpg, один React frontend, PostgreSQL, Nginx; границы модулей фиксируются интерфейсами. Async выбран для одновременной работы операторов и polling без добавления инфраструктуры.
- Альтернативы: микросервисы отклонены из-за distributed transactions и эксплуатации; два frontend возможны позже.
- Последствия: простой deploy и ACID; требуется дисциплина модульных границ. Извлечение сервиса возможно по измеренной нагрузке/командной автономии.

# ADR-002: Идентичность исходного студента

- Статус: принято
- Решение: Excel `id` — неизменяемый строковый `source_id varchar(128)`; внутренний PK — UUIDv7 и не равен `source_id`; `UNIQUE(event_id,source_id)`.
- Регистрация ищет active студента по точным `normalized_full_name + normalized_study_group + event_id`, затем связывается с внутренним `SourceStudent.id`.
- `source_id` используется только для синхронизации импортов. Разные `source_id` автоматически не объединяются; одинаковое ФИО недостаточно для объединения. Совпадение ФИО+группа у разных ID ведёт к ambiguity/warning.
- Альтернатива глобального справочника студентов отклонена: источник не гарантирует глобальность, а требования event-scoped. Если гарантия появится, вводится GlobalStudent + EventEnrollment отдельной миграцией.

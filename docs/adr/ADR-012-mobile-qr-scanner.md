# ADR-012: Библиотека мобильного QR-сканера

- Статус: принято
- Решение: использовать `@zxing/browser` через собственный React-адаптер `CameraScanner`.
- Причины: встроенные TypeScript-типы, активные публикации, `getUserMedia`, выбор задней камеры через `facingMode`, управление жизненным циклом через `IScannerControls.stop()`, работа на базе стандартных API Android Chrome и iOS Safari.
- Ограничения: фактическая матрица устройств проверяется перед мероприятием; torch — фонарик — не гарантируется iOS. Всегда доступен ручной ввод.
- Последствия: debounce одинакового результата выполняется в адаптере, но одноразовость, роли, идемпотентность и конкурентность остаются исключительно backend-инвариантами. Замена библиотеки не меняет API.
